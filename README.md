# 🦊 Slyfox – Landing Page

Landing page desarrollada para **Slyfox**, empresa colombiana de desarrollo de software a la medida, integración de canales, diseño UX/UI y seguridad.

> 📌 Este repositorio contiene la **versión inicial que desarrollé, presenté y fue aprobada por el cliente**.
> El sitio en producción ha evolucionado desde entonces: [slyfox.com.co](https://www.slyfox.com.co/)

## 👨‍💻 Mi rol

Proyecto desarrollado en pareja. Mi compañero inició la base del proyecto y yo desarrollé **la mayor parte del sitio**, incluyendo:

- Construcción de la mayoría de secciones y componentes
- **Diseño responsive** completo (móvil, tablet y escritorio)
- Animaciones de la interfaz

## 💡 Retos y aprendizajes

Los mayores retos fueron **las animaciones** y **adaptar el diseño a todos los tamaños de pantalla**. Este proyecto me permitió trabajar con un cliente real: entregas, ajustes según retroalimentación y presentación final.

## 🚀 Ejecutar localmente

```bash
npm install
npm run dev
```

Abre `http://localhost:4321` en tu navegador.
